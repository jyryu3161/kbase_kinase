# PRD: kbase_kinase

## 목표

kinase 구조 기반 신약설계에서 **"이 복합체를 보고 다음에 무엇을 바꿔야 하는가"**에 답할 근거를 공급하는 지식 베이스를 만든다.

최종 소비자는 사람이 아니라 에이전트다.

> multi-modal LLM이 protein–ligand 복합체를 보고(직접 시각적으로든, 분석 결과로든) 다음 화학구조 변형 전략을 **근거와 함께** 제안한다.

역할 경계를 먼저 못 박는다.

> **KB는 관련 전례와 적용 조건을 공급한다. 새 복합체의 해석과 변형 제안은 소비자 에이전트가 한다.**
> **KB 검색이 성공했다는 사실을 가설이 검증됐다는 뜻으로 해석하지 않는다.**

## 사용자

| 사용자 | 하는 일 | 필요한 것 |
|---|---|---|
| **설계 에이전트** (주 소비자) | 복합체에서 descriptor를 뽑고 전례를 조회해 변형을 제안 | 구조 어휘로 색인된 Move, 적용 조건, 인용 가능한 근거 |
| **코딩 에이전트** | `grep`/`jq`만으로 KB를 뒤짐 | 한 줄 한 레코드의 평면 JSONL, 계약 문서 |
| **큐레이터** (현재 1인) | 논문을 읽고 Move를 승인 | 최소한의 스키마, 테마별 리뷰 큐, 원문 재확인 경로 |
| **데이터셋 작성자** | 학습·평가 세트 생성 | 고정 ID, 논문 단위 분할, 재현 가능한 스냅샷 |

큐레이터가 1인이라는 점이 설계 제약이다. 추출은 싸고 검수는 비싸다. 이 비대칭이 승격 정책을 결정한다.

## 핵심 기능

1. **Design Move 저장** — `구조적 관찰 → 화학적 변형 → 측정 효과 → 트레이드오프 → 근거`를 하나의 레코드로. 측정값은 논문의 표·행·열·assay·단위·부등호·각주까지 고정한다.
2. **구조 어휘 기반 조회** — SITE / GOAL / TACTIC 3축 통제 어휘로 태깅하고, 소비자가 복합체에서 뽑은 descriptor와 같은 축으로 매칭한다.
3. **내성 변이 카탈로그** — 구조적으로 주석된 kinase 내성 변이. 공개된 기계판독 형태가 존재하지 않아 직접 큐레이션한다.
4. **그림 연계** — 논문의 결합 부위 그림과 SAR 표를 패널 단위로 Move에 연결한다. multi-modal 소비자가 이미지를 직접 받을 수 있게 한다.
5. **파일 기반 소비 계약** — `dist/`에 JSONL과 계약 문서를 두고, 서버 없이 여러 애플리케이션이 독립적으로 읽는다.
6. **도메인 파생** — 엔진과 도메인팩을 분리해 같은 구조의 다른 지식 저장소를 만들 수 있게 한다.

## 성공 기준

기능 목록이 아니라 다음 질문에 답할 수 있는지로 판단한다.

- Move 하나를 골라 observation · change · effect **각각을** 원문에서 재확인할 수 있는가
- 예제 질문 5개(근거 있는 질문 / 없는 질문 / 부정 질의 / 미지 ID 포함)에 올바른 응답을 내는가
- 같은 입력으로 재실행했을 때 curated와 dist가 동일한가
- 잘못된 입력 하나가 기존 KB를 손상시키지 않는가

**pytest 통과만으로는 성공 기준이 아니다.** 사람이 원문을 대조한 Move와 소비자 질문 결과를 함께 본다.

## 하지 않는 것

- **논문 데이터베이스를 만들지 않는다.** PMID 수집은 수단이고 목적은 설계 지식이다.
- **구조 예측·도킹·합성 경로를 담지 않는다.** KB에 없는 것은 계약 문서에 명시하고, 에이전트가 지어내지 않게 한다.
- **임의 PDB의 구조 계산을 하지 않는다.** v1은 지원 target에 한정된 레지듀 지도까지다. 그 밖은 `unmapped`를 반환한다.
- **화학 구조 이미지를 SMILES로 읽지 않는다.** 그림은 크롭 이미지로만 보관한다.
- **자유 텍스트 의미 검색을 지원하지 않는다.** 임베딩·벡터 인덱스를 도입하지 않는다.
- **MCP 서버를 지금 만들지 않는다.** 전송이지 기능이 아니다.
- **기계 검사 결과를 사람 검수로 취급하지 않는다.** 이것이 가장 중요한 금지 사항이다.

## 제약

| 제약 | 내용 |
|---|---|
| PDF 확보 | 대상 저널이 대부분 유료다. 44편 표본에서 PMC 전문은 1편이었다. 사용자가 직접 확보해 `sources/pdf/`에 넣는다 |
| 큐레이션 인력 | 1인. 추출은 논문당 센트 단위, 검수는 Move당 수 분이다 |
| 외부 DB 신선도 | KLIFS는 4개 kinase 표본에서 2025년 이후 구조 167건 중 0건을 담고 있다. 실시간 피드로 의존할 수 없다 |
| 라이선스 | 비공개 연구용. COSMIC은 제외한다. KLIFS·Kincore는 라이선스가 명시되지 않아 재배포하지 않는다 |
| 저작권 | 논문 그림은 출판사 저작물이다. 이 저장소는 포크를 전제하므로 공개 산출물은 허용 목록 기반 별도 export로만 만든다 |
